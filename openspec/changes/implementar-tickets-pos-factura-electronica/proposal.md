# Implementar tickets POS y factura electrónica

Agregar dos documentos imprimibles explícitos: ticket de venta POS y representación de factura electrónica aceptada. La impresión usa el Peripheral Agent existente y no cambia datos comerciales ni fiscales.

La visibilidad de Gestión Operativa debe respetar los permisos de menú entregados por el backend para todos los roles POS, manteniendo `OperationalSaleScope` como frontera de datos.
