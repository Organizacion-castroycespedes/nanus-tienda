# Riesgos

- Agent qa.4 está certificado e inmutable; qa.5 necesita nuevo artifact y QA.
- PnP puede exponer identidad incompleta; no fusionar dispositivos sin fingerprint seguro.
- Scanner HID no siempre es enumer able como dispositivo funcional; exigir escaneo real.
- Configuración cloud y estado físico local pueden divergir; UI debe mostrar ambos.
- Cambios de persistencia requieren autorización explícita para ejecutar migraciones.
