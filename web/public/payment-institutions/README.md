# Logos de entidades financieras

Los archivos de esta carpeta se usan solo para identificar visualmente las
entidades en el POS y en su CRUD. Las marcas pertenecen a sus titulares.

Fuentes consultadas:

- Wikimedia Commons, categoria de logos SVG de bancos de Colombia.
- Wikimedia Commons, logos de Nequi, BBVA, Scotiabank e Itau.

`Daviplata` conserva por ahora el fallback visual del componente porque no se
incorporo un archivo local con procedencia verificable.
