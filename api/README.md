# Manus Tienda API - PKG Packaging Guide

## 📌 Overview

This is the **NestJS backend** for Manus Tienda POS system. It has been configured for production deployment as a single executable binary using `pkg` and PM2.

### What's New
- ✅ **Binary packaging** with pkg
- ✅ **PM2 process management**
- ✅ **Production-ready configuration**
- ✅ **Zero Node.js dependency** on target server

---

### For Development
```bash

```

### For Production Binary

## ⚙️ Build & Deploy

### Build Commands

```bash
# Install dependencies
npm install

# Development: Watch mode
npm run start:dev

# Production: Compile TypeScript
npm run build

# Production: Create standalone binary
npm run build:bin
```

### Binary Output
```
dist-bin/
├── api              # Linux x64 executable (~130 MB)
└── api.exe          # Windows x64 executable (~130 MB)
```

### Deployment Commands

```bash
# Start with PM2
pm2 start ecosystem.config.js

# Monitor
pm2 monit
pm2 logs

# Save for startup
pm2 save
pm2 startup
```

## 🔧 Configuration

### Environment Variables
Create `.env` from `.env.example`:

```env
# Server
PORT=4020
NODE_ENV=production
CORS_ORIGIN=https://yourdomain.com

# Database (PostgreSQL)
DB_HOST=localhost
DB_PORT=5432
DB_DATABASE=manus_tienda
DB_USERNAME=postgres
DB_PASSWORD=your_password
DB_SSL=false

# Authentication
JWT_SECRET=your_jwt_secret
JWT_EXPIRES_IN=1h

# Integrations (Optional)
LEADS_WEBHOOK_TOKEN=
GOOGLE_DRIVE_CLIENT_EMAIL=
GOOGLE_DRIVE_PRIVATE_KEY=
```

## 🐛 Troubleshooting

### Binary won't start
```bash
# Check .env exists in same directory as binary
ls -la .env

# Run manually to see errors
./dist-bin/api

# Check logs
pm2 logs manus-api
```

### Database connection error
```bash
# Verify DB connection
psql -h localhost -U postgres -d manus_tienda

# Check .env values
cat .env | grep DB_
```

### Port already in use
```bash
# Change in .env
PORT=4021

# Or kill process
lsof -i :4020
kill -9 <PID>
```

See [PKG_IMPLEMENTATION_GUIDE.md](./PKG_IMPLEMENTATION_GUIDE.md#-phase-6-troubleshooting) for more troubleshooting.
