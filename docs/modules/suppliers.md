# Modulo suppliers

## Proposito

Administra proveedores para compras.

## Endpoints

- `GET /api/suppliers`
- `POST /api/suppliers`
- `GET /api/suppliers/:id`
- `PUT /api/suppliers/:id`
- `DELETE /api/suppliers/:id`

## Campos inferidos

- nombre
- documento
- telefono
- email
- direccion
- departamento/municipio
- `is_active`
