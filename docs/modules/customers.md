# Modulo customers

## Proposito

Administra clientes operativos para POS, ventas y pedidos.

## Endpoints

- `GET /api/customers`
- `POST /api/customers`
- `GET /api/customers/:id`
- `PUT /api/customers/:id`
- `DELETE /api/customers/:id`

## Campos inferidos

- nombre
- documento
- telefono
- email
- direccion
- departamento/municipio
- `is_active`
